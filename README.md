# Taller de Pruebas Unitarias - TDD

Sistema de registro de votantes para la Registraduría Nacional, desarrollado con TypeScript y Jest siguiendo los principios de TDD y Clean Architecture.

## Stack

- TypeScript + Node.js
- Jest (pruebas unitarias y cobertura)
- Clean Architecture

## Ejecutar pruebas

```bash
npm install
npx jest --coverage
```

## Cobertura

100% de cobertura en statements, branches, functions y lines.
